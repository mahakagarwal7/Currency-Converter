


# Currency Converter API (Node.js)

A Node.js application that converts currencies using live exchange rates and lists the countries where the target currency is used.  
It consumes multiple external APIs and follows best practices for environment-based API key management.

---

## 🚀 Features

- Converts between any two currencies
- Uses real-time exchange rate data
- Fetches countries where the target currency is used
- Secure API key handling using `.env`
- Built with Axios and async/await

---

## 🛠 Tech Stack

- Node.js
- Axios
- External REST APIs
- dotenv for environment variable management
